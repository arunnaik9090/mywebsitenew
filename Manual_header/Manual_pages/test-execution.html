Test Execution

Run approved tests against a known build and environment, record evidence, and report failures with enough detail to reproduce.

Before execution

  • Confirm build, environment, configuration, and test data are correct.
  • Check the test run scope, priorities, dependencies, and entry criteria.
  • Verify required accounts, devices, services, and permissions are available.
  • Record known issues and blockers before starting.

Run and record

  1. Follow the approved steps in order and use the stated test data.
  2. Compare actual behavior with each expected result.
  3. Mark each case Pass, Fail, Blocked, or Not Run; do not mark an unverified case as passed.
  4. Capture relevant evidence, such as screenshots, timestamps, request IDs, or logs, while protecting sensitive data.

When a test fails

Recheck the environment and repeat the smallest reliable reproduction. File a defect with build, environment, preconditions, steps, expected and actual results, reproducibility, impact, and sanitized evidence. Link the failing test and retest it after a fix.

Close the test run

Summarize executed, passed, failed, blocked, and not-run cases. List open defects and residual risks, explain scope changes, and state whether the agreed exit criteria are met.
